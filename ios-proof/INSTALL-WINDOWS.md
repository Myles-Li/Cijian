# Windows给自己的iPad安装验证包

适用目标：用户自己的iPad Air，用户提供的iPadOS27.2。用户已用以下路线完成0.1安装并确认基本词卡／声音可用。**0.2尚待在这台iPad重新签名覆盖与实测**。Sideloadly官方声明支持Windows和iOS27系列，不代表本项目已实测其全部组合。

## 两件不同的事

- 我们的云端macOS负责把Swift源码编译成设备程序。
- 你电脑上的签名工具使用你自己的Apple账号，为这台iPad签名和部署。GitHub、LocalSend和普通文件管理器只负责传文件，不能代替签名。

先使用验证包检查画中画和声音是否值得继续，再决定是否购买开发者会员。

## 免费签名路线

1. 等待实际设备目标编译通过，并取得明确标注`UNSIGNED`的验证IPA及SHA256。它没有Apple签名，不能直接点开安装；模拟器`.app`也不能当成iPad程序。
2. 从[Sideloadly官网](https://sideloadly.io/)取得Windows版本。官方要求Windows上的桌面版iTunes和iCloud组件；如果已有Microsoft Store版或Apple Devices，不要为这次验证自动删除现有软件，先确认是否存在组件冲突，再按官网说明处理。
3. 用能传数据的USB线连接iPad。解锁设备，按系统提示信任自己的电脑。先确认签名工具能看见设备，再继续。
4. 将验证IPA拖入Sideloadly，选择自己的设备与Apple账号，开始签名。账号、密码和双重验证码由你在自己的电脑操作，不需要发到聊天中，也不放进GitHub或工程文件。
5. 安装后按系统提示，到设置中信任对应开发者；如果要求开发者模式，参考[苹果开发者模式说明](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device)，允许后通常需要重启并确认。
6. 打开“词间验证”，先确认默认暂停；再测试App内词卡、开始听词和开启画中画。不要直接把安装成功记为后台听词或画中画已通过。

普通免费账号通常每七天要重新签名，且存在设备和App数量限制；自动续签也依赖电脑、设备连接与账号条件。仅为自己的短期验证，不需要先买99美元／年的开发者会员。[苹果免费账号限制](https://developer.apple.com/help/account/basics/about-your-developer-account/) · [工具官方FAQ](https://sideloadly.io/faq)

## 真机验证顺序

| 操作 | 应观察的结果 |
|---|---|
| 首次打开、退出重开 | 默认暂停，没有突然发声 |
| 连续点上一词／下一词 | 正确循环三个样本，没有卡住或重复启动音频 |
| 开始听词 | 日语词头、中文释义能听清；缺少声音必须明确显示 |
| 开启画中画，回到主屏幕或其他App | 小窗仍能看到完整词卡；系统播放／暂停有效 |
| 拖动、缩放、横竖屏 | 词头、假名、释义仍可辨认；长词没有被截断 |
| 关闭画中画／点全部停止 | 没有残留语音；重新开启可用 |
| 后台听词关闭时退出App | 暂停；不能擅自继续听 |
| 开启后台听词并开始后，退出或锁屏 | 连续至少3分钟，实际听到下一词；不能只根据状态标签判断 |
| 蓝牙／耳机断开、音频被打断 | 暂停，恢复后由用户手动开始 |

不测试开机自动弹窗，不测试悬浮收藏／评分按钮；这些不是本验证工程提供的能力。模拟器截图不能代替上述真机检查。

## 需要给别人体验时

TestFlight通常更方便：自己的开发者会员、签名上传、首个外部测试构建审核、对方装免费TestFlight并打开邀请链接。测试者不需要购买开发者会员；每个测试构建90天到期，持续使用需要上传新构建。它不要求先正式上架App Store。[苹果TestFlight说明](https://developer.apple.com/help/app-store-connect/test-a-beta-version/testflight-overview/)

## 已有0.1时升级到0.2

取得明确标注0.2的未签名IPA，拖入Windows上的Sideloadly，沿用之前安装成功的Apple账号和高级设置，再次签名部署；不要先卸载0.1，也不要为了覆盖更改标识。如果签名条件未变化，应覆盖“词间验证”；仍以设备安装结果为准。免费签名的有效期与续签要求不变。

先在“声音与试听”分别试听日语／中文、查看实际音色及质量；需要更高质量时先从系统下载，再回App重新检测。返回主页应保持暂停。再测试画中画中点开覆盖层、是否仍有快进／快退、暂停、全部停止和关闭。系统关闭／返回控件仍会保留，不以“所有视频按钮消失”为验收目标。
