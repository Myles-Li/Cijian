# 从零阅读词间 · Cijian 1.10.5 源码

VS Code 可以阅读、搜索和编辑整个项目。Android Studio 还提供安卓构建、模拟器、断点调试和日志界面；两者打开的是同一份 Java 源码。

## 先打开整个项目

1. 若使用干净源码包，先把 cijian-public-source-1.10.5.zip 解压到一个独立文件夹。不要在压缩包预览中编辑文件。
2. 打开 VS Code，选择“文件 → 打开文件夹”，选择**直接包含 settings.gradle、build.gradle、app 和 docs 的那一层**。不要只打开 app/src，也不要打开 APK。
3. 左侧资源管理器展开 app → src → main → java → com → myles → cijian。这就是应用 Java 代码的位置。
4. 先打开 README.md，再打开本指南；Markdown 可用 Ctrl+Shift+V 预览。docs/词间-完整结构图.html 可用浏览器打开，点功能节点查看对应源码和规则。
5. Ctrl+P 输入文件名快速打开；Ctrl+Shift+F 搜索整个项目；Ctrl+F 搜索当前文件。安装 Java 语言支持并配置 JDK 后，可用 F12 跳到定义、Shift+F12 查找引用。

只读代码无需先安装 Android SDK 或成功运行。安卓项目的 Java 类型依赖 Android SDK；没有配置开发环境时，编辑器红线不一定说明代码有错。

## 推荐阅读顺序

不必按文件数量从头读到尾。每次带一个问题，沿调用关系看一条路径。

| 顺序 | 文件（下文简称省略 app/src/main/java/com/myles/cijian/） | 带着什么问题读 |
|---|---|---|
| 1 | ReviewPlan.java | 评分如何决定下次复习时间？只有几个短方法，适合先看懂 |
| 2 | StudyTasks.java、FirstPass.java | 到期词、新词和“浏览一遍”进度怎样计算？ |
| 3 | Word.java、Prefs.java | 一个词有哪些字段？设置如何读取默认值？Word 也使用安卓数据库 Cursor，可先看字段再看构造方法 |
| 4 | MainActivity.java、Ui.java | 首页、四个主页面和设置如何拼出来？先找 home、settings、render，不必一次读完大文件 |
| 5 | BrowseActivity.java、StudySession.java、ShuffleDeck.java | App 内浏览怎样取词、翻词和避免整轮重复？ |
| 6 | FloatService.java、DragLayout.java | 悬浮窗怎样出现、移动、滚动、收球和关闭？ |
| 7 | ReviewActivity.java、ReviewFlow.java、ReviewDraft.java、ReviewSession.java | 正式回忆如何揭晓、评分，以及中断后续接？ |
| 8 | WordStore.java | 上述动作最终如何读写 SQLite、用事务避免重复评分？ |
| 9 | SpeechPlan.java、Speech.java、AudioGuard.java | 朗读队列、系统引擎和音频中断分别由谁处理？ |
| 10 | BackupFiles.java、BackupPreview.java、BackupSettings.java、RestoreSafety.java | 导出、预览、校验和恢复撤回如何配合？再搜索 WordStore 中的 backup 和 restore |

“语言与外观”页恢复默认会保留界面语言，只重置外观选项；确认框会说明这个范围。

其他常用入口：ThemePicker.java 管主题色选择；L.java 和 assets/ui-en.json、assets/ui-ja.json 管界面翻译；SettingIndex.java 管设置搜索；Tutorial.java、ReviewGuide.java 管使用与复习说明。

## 用三个例子串起来

**“为什么点记得后隔几天再来？”**

先看 ReviewPlan.nextStage 和 delay，再看 tools/tests/LogicTests.java 中的 ReviewPlan 断言。接着看 ReviewFlow.answer：它不是只换一行文字，而是复制草稿、计算下一步并提交状态。最后在 WordStore 中找 rate 和草稿提交，理解评分与任务推进的事务边界。正式界面有两个，评分逻辑共用。

**“为什么这版详情可以横向拖动，但上下还能滚动？”**

在 DragLayout 找 shouldDrag、scrollGesture 和 requestDisallowInterceptTouchEvent。再到 FloatService 搜索 new DragLayout，看位移回调如何更新窗口位置。ScrollView 内纵向起手留给滚动，横向起手用于移窗；已开始的纵向滚动不会中途被抢走。位置锁定和多指取消也是同一层处理。

**“切换两种节奏为什么不再闪占位数字？”**

在 MainActivity 搜索 chooseStyle、cachedHome、homeKey 和 refreshHome。有效的同范围／同日期快照先填进新视图，再异步核对最新数据；范围改变不会套用旧范围数字。searchGeneration 用于拒绝已经过期的查询结果。查询期间若日期或范围键变化，会重新查询，保留后续刷新。缓存改善显示，不是新的学习记录来源。

## 看懂目录和技术栈

应用本体主要用 Java；XML 放安卓资源和配置，Gradle 文件描述构建方式。Python 文件用于电脑上的构建、整理和测试，手机运行应用不依赖 Python。

- app/src/main/AndroidManifest.xml：页面、服务、权限和启动入口。应用没有 INTERNET 权限，外置语音引擎的网络行为由引擎决定。
- app/src/main/java/：Java 应用代码，使用 Android 原生 View；这个项目的许多页面在 Java 里创建，不是每个页面都有 layout XML。
- app/src/main/res/：主题、字符串、图标和系统配置等资源。app/src/main/assets/vocabulary.db 是随包的 SQLite 词库，不是文本源码。
- app/src/androidTest/：需要安卓环境的测试。含专用测试数据和静音测试语音引擎，不打进生产 APK。
- tools/tests/ 与 tools/test_logic.py：无需手机的 Java 纯逻辑检查。
- build.gradle、settings.gradle、app/build.gradle：Gradle 构建配置；app/build.gradle 中有版本、最低系统和 Java 版本。
- docs/：规则说明、结构图和维护资料。结构图帮助找入口，实际行为仍以代码和测试为准。

Activity 可以理解为一个应用页面；Service 是没有普通页面的服务；View 是按钮或文字等界面部件；SharedPreferences 保存轻量设置；SQLite 保存词与学习记录；Handler 把结果送回界面线程。Async.IO 处理后台任务，不能直接操作界面控件。

## 想运行时

最省步骤的方式是用 Android Studio 打开同一项目根目录，使用 JDK 17 和 Android SDK 35，等待 Gradle 同步后，选择专用模拟器运行 app。也可按 README 使用 Gradle Wrapper 构建。首次配置与下载依赖需要网络。

只运行纯逻辑检查：安装 JDK 17 和 Python，在项目根目录终端执行 python tools/test_logic.py。看每条断言怎样把需求变成“应当发生”的结果，再改变自己的实验副本观察测试报错，会比盯着大量代码更容易理解。

干净源码不含作者发布私钥，自行构建的签名与正式安装包不同。学习实验建议用独立副本和模拟器，不要卸载日常使用的词间来迁就开发签名，也不要对日常手机运行重建测试数据的脚本。

第一次练习建议：在实验副本中修改一条教程文字，确认它在哪个文件、怎样通过 L.t 查表、是否需要同步另外两种界面语言。之后再试着理解一条纯逻辑测试。正式评分、备份恢复和数据库迁移留到理解事务和边界之后。

## 本项目的实际取舍

这是一个功能较多、主要使用原生 Java View 的个人应用；MainActivity 和 FloatService 仍较大，并非学习安卓架构的唯一范本。可以学它怎样把规则、记录、界面和验证串起来，也应辨别哪些部分以后值得拆小。不要把测试数量理解成所有手机绝不会出问题；真实语音、厂商后台策略和功耗有单独的真机验证边界。

## 1.10.0可以接着读的代码

- FontPicker.java和Prefs.appSize：App内与悬浮窗字号分开保存，sp继续尊重系统字体。
- SwipeCardLayout.java：区分横滑、纵滑、点击、多指与取消；BrowseActivity复用按钮的flip方法。
- PositionLock.java与FloatService：顶部锁的绘制、可访问状态和实际窗口锁定。
- Ui.exampleAction与Speech.isSpeakingExample：紧凑例句按钮只控制本次手动例句，避免把正在读的单词误当例句。
- BackupSettings.java：新增四项设置的类型和范围校验；未改变词库与正式复习数据库结构。

## 源码包名与安卓安装标识

1.10.1的源码包和安装标识均为com.myles.cijian；MainActivity为新启动入口，WordStore使用cijian.db。BackupFormat统一识别新版cijian-progress-v2和旧版v1/v2备份。对照WordStore.backup／restore、BackupPreview与RestoreSafety，理解导出、预览、恢复和撤回如何协作。

1.10.5可直接覆盖同签名的1.10.1，保留记录和未完成批次。只有从1.10.0及更早版本迁移时，才需先导出旧版JSON，在Cijian中恢复；该跨应用迁移不含未完成批次，系统权限需要重设。[迁移步骤](从旧版迁移.md) · [名称与迁移标识](命名与兼容.md)。

## 1.10.5的修改入口

BrowseActivity把SwipeCardLayout放在整个学习页根部；原词卡恢复为普通容器，横滑仍复用flip。SwipeCardLayout的multiple状态防止第二指触发子控件点击。Ui.actionRow只给操作按钮间增加4dp分隔；Speech.summary用于简短状态，详细信息留在设置页。MainActivity的openVoiceSettings入口与返回学习配合BrowseActivity的返回重检标志，返回保持暂停。
