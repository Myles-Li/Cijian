# 旧版迁移与1.10.5更新

**已使用1.10.1：安装官方同签名1.10.5直接覆盖，不先卸载，保留记录和未完成批次。**

仍使用1.10.0或更早版本：1.10.1及以后采用新的安装标识，会与旧版并存。请先别卸载旧版。 新旧应用图标和名称相近，可以从系统应用信息中的版本号辨认。

1. 在旧版关闭悬浮学习，进入「设置 → 备份与帮助 → 备份学习记录」。选择分享备份或保存文件，把JSON保存到自己找得到的位置；保留这份原始文件。
2. 安装1.10.5，打开新应用确认版本。旧版仍保留在手机上，记录不会自动出现在新应用中。
3. 在新应用的「恢复学习记录」选择刚才的JSON。先核对预览，可选择只导入记录，或同时恢复设置；按页面提示确认。
4. 核对收藏、熟悉、浏览进度、正式复习及学习范围；需要时可「撤回上次导入」。确认迁移完整后，再自行决定是否卸载旧应用。
5. 为新应用重新允许悬浮窗和通知，需要后台运行／开机恢复时重新检查系统设置。外置语音引擎沿用手机已安装的引擎，可先试读日语和中文。建议同一时间仅开启一个版本的悬浮学习。

## 能迁移什么

JSON包含收藏／手动熟悉、遇见与初见证据、正式复习安排与每日记录、易忘证据、标记修改时间，以及可选的学习与外观等设置。导入沿用现有合并规则；不会无条件清空新应用已有的记录。新安装后立即迁移最容易核对。

未完成的正式批次、临时撤销历史、正在播放的声音、系统权限和运行中的悬浮窗不在JSON备份中。已提交评分会保留，未完成批次在新应用重新安排；原批次仍留在旧应用中。不要把系统权限已转移或旧批次可直接续接当作成功条件。

旧版导出的两种格式均受支持：kotoba-float-progress-v1、kotoba-float-progress-v2。新版导出采用cijian-progress-v2、文件名cijian-backup-*.json，保存文件选项默认使用Download/Cijian。旧应用不支持新版格式，因此保留旧JSON作为回退备份。

## 测试范围

专用Android15模拟器使用真实官方1.10.0生成旧备份，逐项核对八类记录和所有已导出的设置，验证只恢复记录、同时恢复设置、导入撤回、新格式分享读取、旧v1/v2识别及新旧UID隔离；另核对旧应用的记录、设置和未完成批次没有变化。实际结果与安装包指纹见[验证记录](VALIDATION.md)。红米等厂商的权限页面、后台策略及真实声音需在手机上确认。
