# 名称与兼容标识

当前产品统一称 **词间 · Cijian**，中文和日文界面显示“词间”，英文界面显示“Cijian”。仓库、Gradle 工程展示名和下载页使用 Cijian。

早期工程名是 Kotoba Float。以下旧标识用于连续升级、记录和工具兼容：

| 旧标识 | 用途与原因 |
|---|---|
| com.myles.kotobafloat | Android applicationId、Java 包及应用沙盒身份；更换后无法直接覆盖旧安装及沿用其数据 |
| kotoba.db | 本地学习数据库名 |
| kotoba-float-progress-v1/v2 | 备份格式识别串，兼容旧备份 |
| kotoba-backup-*.json、Download/Kotoba | 现有 1.9.5 的备份文件名前缀和保存目录，可在文件管理器中据此找到原备份 |
| KOTOBA_STATE、日志标签、测试辅助标识 | 本地诊断与旧测试脚本识别 |

这些标识不表示另一个应用。此次 GitHub 发布提供原已验收 1.9.5 / 构建14安装包，未为了修改旧目录名重新构建。词库中日语“ことば”等词条及罗马字检索内容属于学习数据，保持原义。
