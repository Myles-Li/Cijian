# 名称与迁移标识

1.10.1按作者决定完整更换为 **词间 · Cijian**。源码包、namespace及Android安装标识均为 `com.myles.cijian`。它是一个新应用，会与1.10.0及更早版本并存，不能覆盖旧应用的数据空间。

| 标识 | 1.10.1起沿用 |
|---|---|
| 安装标识／源码namespace | `com.myles.cijian` |
| 源码目录 | `app/src/main/java/com/myles/cijian` |
| 启动页面 | `com.myles.cijian.MainActivity`，不保留旧启动别名 |
| 本地学习数据库 | `cijian.db` |
| 备份分享地址 | `com.myles.cijian.backups` |
| 新备份格式 | `cijian-progress-v2` |
| 新备份文件／默认保存位置 | `cijian-backup-*.json`／`Download/Cijian` |
| 服务指令／内部诊断 | `com.myles.cijian.*`／`CIJIAN_*` |

旧的 `kotoba-float-progress-v1` 和 `kotoba-float-progress-v2` **仅作为旧JSON备份的导入识别串保留**，见BackupFormat.java。1.10.1新导出的格式不能交给旧应用读取，请保留原始旧备份。历史归档、旧Release及词库原始文件不改写。

Android用applicationId识别应用，详见[官方文档](https://developer.android.com/build/configure-app-module)。改成新标识会使用独立UID、记录和权限；相同签名也不会自动转移旧数据。系统悬浮权限、通知权限和电池策略须为新应用重新设置。签名密钥不随产品改名更换。

迁移操作见[从旧版迁移](从旧版迁移.md)。先从旧版导出，安装新应用后导入核对，确认前不要卸载旧版。没有自动扫描或读取另一个应用的私有数据库。

1.10.5继续使用相同的com.myles.cijian、签名、数据库和备份标识，可直接覆盖1.10.1。旧版迁移提示只适用于1.10.0及更早安装标识。
