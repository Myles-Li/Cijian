# 构建与测试

## 本机纯逻辑

安装 JDK 17 和 Python，在项目根目录运行 `python tools/test_logic.py`。覆盖队列、分组、每日目标、复习规则、搜索、易忘词、音型与发音等纯逻辑。

## 安卓构建与静态检查

Windows：`gradlew.bat :app:assembleDebug :app:lintDebug :app:assembleDebugAndroidTest`。macOS/Linux：`sh ./gradlew :app:assembleDebug :app:lintDebug :app:assembleDebugAndroidTest`。使用 Android SDK 35、Build Tools 35.0.0、JDK17。首次构建需联网取得工具和依赖。

## 设备专项

app/src/androidTest 内含完整的原生专项检查及测试夹具。部分测试会重建学习数据、替换偏好或使用静音TTS，限专用可丢弃模拟器，不对日常手机运行。1.9.5 的最终验收在 Android15 / API35 的专用模拟器执行；真实语音、厂商后台与功耗需要真机确认。

GitHub 自动检查只运行纯逻辑、构建、lint和测试包编译，不宣称云端重跑了全部设备流程，也不上传调试APK。官方APK与最终本地设备验收记录见 [VALIDATION.md](VALIDATION.md)。公开源码没有发布签名配置，默认debug开发签名不能覆盖官方安装包。
